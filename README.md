# EletroRecicla — Frontend

Recriação visual do protótipo Figma em React + Vite + TypeScript.

## Executar

```bash
npm install
npm run dev
```

## Compilar

```bash
npm run build
```

## Situação

O frontend usa dados demonstrativos nas telas internas. Login, cadastro, exportação e recompensas ainda não se comunicam com a API. Não há alterações no backend.

As cores da identidade visual foram aproximadas a partir das imagens; medidas e hex exatos ainda dependem da verificação no Dev Mode do Figma. A comparação visual final também está pendente.

Esta é a reconstrução limpa no repositório **frontend10**, não o antigo **frontend1010**.
